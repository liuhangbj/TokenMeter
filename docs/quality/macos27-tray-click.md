# macOS 27 菜单栏左键兼容修复

## 需求与范围

- 用户实测：升级 macOS 27 后，左键单击菜单栏图标只弹“刷新额度 / 退出”，
  不打开主面板。用户同意兼容修复与本机真实验证；不含提交、推送或发布。
- 本机：macOS 27.0 (26A428)，Apple Silicon；日常 App 0.9.10。
- 风险 R3：平台窗口入口与原生菜单；目标 M01/M12，相邻 M06/M10。
- 基线 HEAD `ef5cb90`，工作区已有 Windows 悬浮球修复和质量文档改动，保留。
- 本轮仅修复托盘库 macOS 菜单绑定，不改账户、凭证、Provider、卡片或主题。
- 依据：tray-icon #355 与用户现象一致，采用 #365 的固定提交补丁。
  来源及移除条件见 `src-tauri/vendor/tray-icon/TOKENMETER-PATCH.md`。

## 架构与数据保护

托盘库 0.24.2 项目内副本通过 Cargo path patch 使用，只改 macOS 实现，
不修改全局 registry，不拉取浮动 Git 依赖。保留 MIT/Apache 许可证。
菜单在原生弹出期间临时挂载，结束后解除；macOS menu ivar 的 RefCell 借用在
进入嵌套事件循环前释放。公开 show_menu 包装层的外层借用限制保持不变，
TokenMeter 当前不调用该程序化路径。
本轮实际运行候选从 HEAD 加本补丁构建，不夹带工作区未提交的 Windows 修复。
先隔离数据自验，成功后才替换本地日常 App；保留旧包供回退。
不读取或输出凭证明文，不将真实凭证用于故障注入。
