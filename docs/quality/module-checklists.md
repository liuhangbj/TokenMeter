# TokenMeter 模块质量与回归清单

本文件是长期维护的模块级质量索引，防止功能完成或共享迁移时依赖人工记忆。
它把每个模块的技术审核和真实 App 验收放在同一位置。

## 使用规则

1. 主开发 Agent 在任务契约中选择目标模块、至少一个上游入口模块和一个
   下游结果模块。
2. 独立审核 Agent 执行所选模块的"技术审核"列。
3. 最终验收 Agent 操作真实 App 执行"真实 App 验收"列。
4. 修改卡片契约、主题变量或共享状态时，必须在三套主题 × 明暗外观中
   验证同一模块。
5. 每项记录 `PASS`、`FAIL`、`BLOCKED` 或有原因的 `N/A`，并附证据。
6. 新增正式功能时同步补充本文件；删除既有功能必须有明确产品决定，
   不能直接从清单消失。

供应商字段细节以 `../01-provider-matrix.md` 为准；卡片结构以
`../05-provider-card-contract.md` 为准；主题槽位以 `../07-theme-contract.md`
为准。
